# Existing photograph release

The owner authorized using online photographs for the existing nine Council seats. The mounted reader already supports `owner_selected_existing_images`; this release supplies its actual 27 WebP assets and complete manifest. It does not represent the people as participants or claim endorsement.

`portrait-photo-sources.json` records each source URL, source-byte SHA256, EXIF-normalized pixel dimensions, exact crop rectangle and prepared PNG hash. Public `credits.html`, linked from the Council page footer, records attribution, published license information and transformations. Brené Brown derivatives retain CC BY-SA 4.0. For the three press/bureau photographs with no general reuse license stated, that absence remains explicit. Manifest rights remain `unverified`; no identity-review or ownership sign-off is invented.

Preparation is local and deterministic: download the listed source, verify its SHA256, apply EXIF orientation, convert to RGB, crop the listed `(left,top,right,bottom)` rectangle without retouching, and save `<seat-id>.png`. The builder's explicit `--owner-selected-existing-images` mode accepts these 4:5 PNGs, requires exact seat names and selected-master hashes, and generates the existing 512×640, 800×1000 and 160×200 variants within their payload budgets. Jakes and Tiffany start below detail resolution and are upscaled; no higher-resolution detail is claimed. Original editorial-art mode retains its review, transparency and minimum-resolution requirements.

Invoke `python3 scripts/council/build_portrait_assets.py --masters <prepared-png-folder> --provenance <selection-json> --output <new-output-folder> --owner-selected-existing-images`. Selection JSON has exactly nine seat keys with selected_subject, selected_master_sha256, rights_status=unverified, creation_method, source_note and alt_text. Preserve credits.html when adopting a rebuilt output. No paid image model, face generation or image identity inference is used.
